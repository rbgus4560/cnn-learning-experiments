# 실험 구성과 결과 해석

## 비교 실험

공통 조건은 Seed 42, 30 Epoch, Batch Size 64입니다. Fashion-MNIST 입력은 28×28, Furniture 입력은 128×128 RGB입니다. 개별 설정은 노트북 설정 셀과 각 summary.csv가 기준입니다.

Furniture는 기본 FC128·Dropout 0.3에서 시작하여 Dropout 0.5, SpatialDropout, FC64를 단계적으로 누적합니다. 변경에 따른 학습 곡선과 클래스별 지표를 비교하는 것이 목적입니다. 프레임워크별 수치 차이를 프레임워크 자체의 인과 효과로 단정하지 않습니다.

## 모델 선택

final_test_accuracy는 마지막 Epoch, best_test_accuracy는 검증 손실 최소 체크포인트의 테스트 결과입니다. 둘을 같은 지표로 섞지 않습니다. 예를 들어 Keras/Adam Furniture Baseline의 마지막 테스트 정확도는 약 50.47%지만 선택 체크포인트는 100%입니다. FC64의 마지막 결과 99.60%와 비교해 단순한 정확도 개선율을 주장하지 않습니다.

## 검증 성능 변동 분석

별도 PyTorch/Adam 실험에서 기본 모델, BatchNorm 제거, 학습률 0.001→0.0001 조건을 비교합니다. 후반 10 Epoch 검증 정확도 변동폭은 기본 약 75.97%p, BatchNorm 제거 약 2.83%p, 학습률 감소 약 23.43%p로 기록돼 있습니다. 이 실행에서는 BatchNorm 제거 조건의 변동이 가장 작았으며 유일 원인 입증이나 반복 실험의 통계적 결론은 아닙니다.

이 결과는 검증 지표의 변동을 관찰하고 가설을 나누어 비교해 본 학습 경험으로 사용합니다. 실행 날짜와 개인의 당시 판단 과정은 자료에 없는 부분을 새로 만들지 않았습니다.
