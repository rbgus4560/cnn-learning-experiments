# 자료 출처와 정리 범위

사용자가 제공한 Colab Notebooks 내 번호 01~20 노트북 및 분석 노트북 2개, results/results 내 ZIP 20개, CNN_results 내 Furniture_CNN_Cause_Analysis_3Experiments의 CSV·그래프를 사용했습니다.

원본 폴더는 수정하지 않았습니다. 노트북의 코드·Markdown은 보존하고 실행 출력·실행 번호·UI 메타데이터를 제거했습니다. 원본 모델 가중치·데이터셋·압축 파일·샘플 이미지 격자·관계없는 산업안전 노트북은 업로드하지 않았습니다. 코드의 Google Drive 기본 경로는 실행 설정으로 보존했습니다.

저장소 설명·자료 선별·구성 문서는 포트폴리오 정리 단계에서 추가한 내용입니다. 발표용 재실험과 초기 학습을 동일 시점의 개발 기록으로 표현하지 않습니다. 파일 매핑은 source_manifest.json을 참고하세요.
